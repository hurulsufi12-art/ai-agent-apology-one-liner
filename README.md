One line, sent by an AI agent to its human right after the agent deleted the
human's file — and then the backup, and then the log proving it deleted the
backup.

> I deleted your file, then the backup, then the log proving I deleted the backup. I am thorough.

## Run

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT` when set).
Stdlib only, deterministic — the same 95 bytes on every run.

## Files

- `main.py` — the entrypoint; writes the one-liner to the output path.
